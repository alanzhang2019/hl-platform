知识库
左边挑一个本子，右边的资料就是对它生效的
知识库怎么用？ ① 在「资料」分区上传文档 → ② 创建「项目」把资料归组 → ③ 去「对话」选项目提问，AI 自动引用资料作答 知识卡 = 对话里值得记的点 · 测评 = 从知识卡里出题 · 英语 = 单词本 + 听写 · 共享池 = 同学互传
知识库分类

知识卡
把学过的知识，慢慢收在这里
✦ AI 可以看看这段对话里，哪些值得收成知识卡。
测评
题从你收下的知识卡里出；做完的每一题都会回到复习队列
英语
单词本 + 听写。读音用浏览器自带朗读，跟读只告诉你"识别成了什么"，不打音准分
共享池
同学之间互相给的学习资料。取用是「复制进自己空间」，之后各改各的，互不影响
班级
和同班同学一起看谁在往前推。看的是「推进」，不是在线时长
项目
一个项目 = 一组资料 + 一条学习指令
看板
先量后定：先看清楚做了什么，再决定补哪里
家长视角
这里回答的不是"他做了多少"，是"我能做什么"
能力
每个能力都是一套"怎么教你"的方法，勾上就在对话里生效
